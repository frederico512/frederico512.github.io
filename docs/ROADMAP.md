# Website Roadmap

This is a flexible sequence, not a deadline. Complete each stage when it adds real value.

## Stage 1 — Simple personal website (current)

- [x] Create a semantic HTML homepage.
- [x] Add a responsive visual foundation in plain CSS.
- [x] Add a small JavaScript enhancement for the footer year.
- [x] Add README, project context, coding standards, and Codex instructions.
- [ ] Replace the visible placeholders with owner-approved content.
- [ ] Review the design together and adjust typography, colours, and spacing.
- [ ] Check the site at mobile and desktop sizes.
- [ ] Create the first Git commit.

## Stage 2 — Personal identity and portfolio content

- [ ] Choose the site name and visual direction.
- [ ] Write a concise introduction and About section.
- [ ] Select real projects and write accurate descriptions.
- [ ] Decide which email address and social profiles should be public.
- [ ] Add a favicon and appropriate social sharing image.

## Stage 3 — Quality and publishing

- [ ] Complete keyboard and accessibility checks.
- [ ] Validate HTML and review browser console output.
- [ ] Choose hosting and connect a custom domain if desired.
- [ ] Configure deployment and verify the production URL.
- [ ] Review privacy, metadata, and public-facing content.

## Stage 4 — Grow only when useful

Possible future work:

- Separate About, Projects, and Contact pages.
- Individual project detail pages.
- A blog or notes section.
- A real contact form, with a secure backend or approved provider.
- A static site generator or framework, if the content or interactions justify it.
- A small test and lint workflow.

Do not start Stage 4 just because the options exist. Keep the site simple until a real need appears.
